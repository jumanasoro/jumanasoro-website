# JumaNasoro.com WordPress theme

Custom WordPress theme for JumaNasoro.com. Content is edited in wp-admin; this repository holds layout and features only.

- `inc/` – content types, custom fields, Site Profile settings, forms, SEO, one-time starter content
- `template-parts/` – reusable components (cards, forms, explorer, CTA band)
- `assets/` – CSS, JS, images

Deploys to Hostinger at `public_html/wp-content/themes/jumanasoro` (Git deployment). No secrets are stored in this repository.
